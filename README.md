# Shorts pipeline: 35 відео для YouTube Shorts і TikTok

Бере `scripts.md` (озвучка + video prompt для кожного з 35 відео) і збирає вертикальні відео 9:16:
AI-голос, AI-картинки за твоїм video prompt, повільний зум, субтитри по словах.

## Запуск (безкоштовно, GitHub Actions)
1. Створи репозиторій на GitHub і завантаж усі файли (разом із папкою `.github`).
2. **Actions → Generate videos → Run workflow**.
3. У полі `niche` впиши частину назви ніші (наприклад `Cosmic`), щоб зібрати лише її. Порожнє поле збирає всі 35.
4. Коли запуск завершиться, завантаж `videos-...` з розділу Artifacts. Усередині папки по нішах: `.mp4` і `metadata.md`.
5. Залий відео вручну на YouTube Shorts і TikTok з позначкою «AI-generated content».

Порада: збирай по одній ніші за запуск (5 відео, ~20 хв). Так архів менший, а помилка в одній ніші не зупинить решту.

## Налаштування
- Тексти і промпти: `scripts.md` (той самий формат: `##` ніша, `###` відео, `**Voiceover**`, `**Video prompt**`).
- Голос, стиль картинок і хештеги по нішах: словник `NICHES` у `generate.py`.
- Якщо безкоштовний сервіс картинок зміниться, задай свій у змінній `IMAGE_URL_TEMPLATE` (з `{prompt}` і `{seed}`). Якщо картинка не завантажилась, ставиться темний фон.

## Важливо
Це ілюстративні AI-картинки, а не справжні відеозаписи. Промпти ніш AI Tool Radar, BlockWorld Stories, Auto Fix Explained і Restore Lab просять реальний запис екрана, гри чи ремонту, тому такі відео краще позначати як ілюстрації або замінити кадри своїми записами. Факти в сценаріях (особливо космос і авто) перевір перед публікацією.
